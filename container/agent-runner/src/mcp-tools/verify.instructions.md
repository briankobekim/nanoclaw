`run_checks({ handoff_id })` asks the host to run a delivered handoff's CHECKS at its CHECKPOINT offline, one disposable read-only container per check. Never run checks yourself. The reply is a system message with the host-derived `verdict`, `error_reason`, a line per check (`exit`, `timed_out`, `removed`), and the host-attested `record_sha256`. Quote it in your review. A refusal names its reason; do not retry more than once.
