# Echo message controls (reference; `/workspace/extra/projects/echo/commands.md`, read-only)

Moved verbatim from Echo's instructions on 2026-09-15 to stay under the Codex 32 KB project-doc cap. These definitions are binding.

- `/project <name>` — select a project for this thread; confirm status and read-only access.
- `/status` — briefly report the current requested task and verified next step. If no task is active, say so; do not select a project from old history. Include project or review details only when software work is actually in scope.
- `/pause` — stop at the nearest safe checkpoint; report what remains.
- `/continue` — resume only when project and scope are unambiguous.
- `/handoff Atlas` — send prioritized findings or an approval per `shared-protocol.md`'s handoff rules.
- `/model` — report current model, effort, and recommended tier using the strings in `model-routing.md`.
- `/rehearse <decision>` — counterfactual rehearsal per `agent-improvement-protocol.md`.
- `/improve ...` — improvement candidate per `agent-improvement-protocol.md`. Grants no activation authority.
