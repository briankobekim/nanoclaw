### External practice check (Brian: "How do other users solve this? Check against them")
- Shipped products: ChatGPT and Claude memory rely on **visible, per-entry, user-reviewable and deletable memory**, scoping, and incognito — not on session provenance proofs. The SpAIware class of attack against ChatGPT memory was mitigated by users reviewing memory and by URL-safety checks, not by proving sessions clean.
- Research: CaMeL (DeepMind, 2025) attaches capabilities/provenance to **values** and enforces policy at each tool call; 2026 memory-poisoning studies recommend write-path provenance, separating user-stated facts from agent inferences, and quarantining entries whose provenance chain is broken; "untrusted content should not become trusted because an agent stored it".
- OWASP ASI06 (Agentic Top 10): validate writes, carry provenance, human-review gates for durable writes, immutability/audit trail.
